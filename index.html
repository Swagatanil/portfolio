Salon booking and admin system Live, final features in progress

A website for Naya Andaz Salon with a real backend behind it. Customers book online and leave feedback, and the owner runs everything from an admin panel without touching any code.

Online booking Feedback with approval Editable rate list Admin panel WhatsApp button

How it behaves:

  • A customer picks a service, date and time. A slot that is full is refused, so there are no double bookings.
  • Spam control: one mobile number cannot make more than five bookings in a day, and past dates are rejected.
  • The owner confirms or cancels bookings, approves feedback before it appears on the site, and edits services and prices.
  • The admin side is locked with a secret token.

It runs on Cloudflare’s free plan, so hosting costs nothing at this size.

Transformer health monitoring In progress: software built, hardware next

A monitoring system for power transformers. The software side is built and runs today on simulated data. Connecting real ESP32 sensors is the next step.

Health score Fault classification Anomaly detection (machine learning) Telegram alerts PDF maintenance reports Reading log

It reads the data, calculates a health score, classifies the fault, flags unusual patterns with an Isolation Forest model, can send alerts on Telegram, logs every reading and creates a PDF maintenance report. When the hardware is ready, only one function in the code needs to change.

Python scikit-learn Telegram Bot API Render
